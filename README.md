# Application
This is a code to make a simple application where people can write anything and send and the content on public. Everyone will have the access of your content but your account.
# Features
You can sign up, and a confirmation code will go to your email you have written and then your account will be made. You can log in, if you already have a account here then you just need to input your email and password. You can post text, you can write something and post it and it will be public for everyone. You can see the content as well, you will need to insert the number of the content and you will get it.
